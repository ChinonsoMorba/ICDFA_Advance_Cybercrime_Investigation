# CCSA104 Security Policy Lab

## Overview
This repository contains the completed CCSA104 Security Policy Lab submitted by Morba Chinonso as part of the Check Point Certified Security Administrator (CCSA) training.

## Lab Objectives
The lab demonstrates core Check Point Security Management and Security Gateway administration tasks, including:

- Exploring the default security policy
- Building an Access Control rulebase
- Organizing rules using policy sections
- Configuring Hide NAT
- Testing rule order and policy installation behavior
- Answering practical security policy and firewall management questions

## Tasks Completed

### Task 1: Explore the Default Policy
- Identified the active policy package.
- Examined the default Cleanup Rule.
- Customized rulebase columns.
- Reviewed Global Properties and Policy Packages.

### Task 2: Build the Access Control Rulebase
- Created and configured Access Control rules.
- Applied appropriate sources, destinations, and services.
- Verified rule placement and policy behavior.

### Task 3: Organize the Rulebase
- Grouped rules using policy sections.
- Verified that sections improve administration without affecting enforcement order.

### Task 4: Configure Hide NAT
- Configured automatic Hide NAT for the Internal_LAN network.
- Verified many-to-one address translation.
- Reviewed Port Address Translation (PAT) behavior.

### Task 5: Rule Order and Installation History
- Tested security policy rule evaluation order.
- Compared the behavior of specific and general rules.
- Reviewed installation history and policy deployment results.
